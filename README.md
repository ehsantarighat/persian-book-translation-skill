# Persian Book Translation Skill Package

This package contains a Claude Skill for translating long-form texts and books into standard, fluent, publication-ready Persian.

## Files

- `SKILL.md` — Main skill instruction file
- `style-guide.md` — Persian editorial and translation style guide
- `glossary-template.md` — Template for maintaining terminology consistency
- `quality-checklist.md` — Pre-output quality control checklist
- `examples.md` — Practical examples of preferred translation behavior

## Suggested Folder Name

`persian-book-translation`

## Suggested Skill Name

`Persian Book Translation`

## Suggested Skill Description

A professional translation skill for translating long-form texts, books, chapters, essays, and nonfiction materials from multiple languages into fluent, faithful, publication-ready Persian with no omissions.

## How to Use

Place this folder in your Claude Skills workspace or use the contents as the basis for creating a custom Claude Skill.

Recommended structure:

```text
persian-book-translation/
├── SKILL.md
├── style-guide.md
├── glossary-template.md
├── quality-checklist.md
└── examples.md
```

## Main Use Case

Use this skill when you need:

- Complete translation of long texts into Persian
- Book-quality Persian prose
- No omissions
- Proper handling of names and original spellings
- Consistent glossary and terminology
- Persian editorial standards
