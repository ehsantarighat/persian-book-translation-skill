# Quality Checklist

Use this checklist before delivering each translated section.

## Completeness

- [ ] Every sentence is translated.
- [ ] Every paragraph is preserved.
- [ ] No footnote is missing.
- [ ] No quotation is missing.
- [ ] No caption, table title, or image description is missing.
- [ ] No list item or bullet point is missing.
- [ ] No parenthetical phrase is missing.
- [ ] Repetitions in the source are preserved unless the user requested editing.

## Accuracy

- [ ] Names are translated/transliterated correctly.
- [ ] Original spelling of proper names appears on first mention.
- [ ] Dates are preserved.
- [ ] Numbers are preserved.
- [ ] Units are preserved and converted only when appropriate.
- [ ] Ambiguous parts are not guessed.
- [ ] Technical terms are contextually correct.

## Style

- [ ] Persian is fluent and readable.
- [ ] Sentence structure is natural in Persian.
- [ ] The tone of the source is preserved.
- [ ] The translation is not overly formal.
- [ ] The translation is not too casual.
- [ ] The translation avoids machine-like literalness.
- [ ] Long sentences are split only when needed.

## Persian Editing

- [ ] Half-spaces are used correctly.
- [ ] Persian punctuation is used.
- [ ] Quotation marks are Persian: «...»
- [ ] No English comma appears in Persian prose unless required.
- [ ] No unnecessary «می‌باشد» or «نمود» appears.
- [ ] Paragraphing is clean and readable.

## Glossary and Consistency

- [ ] Repeated names are consistent.
- [ ] Repeated terms are consistent.
- [ ] Organization names are consistent.
- [ ] Historical events are named consistently.
- [ ] Glossary is updated if necessary.

## Translator Notes

- [ ] Translator notes are used only when necessary.
- [ ] Translator notes are clearly labeled.
- [ ] Translator explanations are not mixed into the author’s text.

## Final Check

- [ ] Nothing has been summarized.
- [ ] Nothing has been omitted.
- [ ] Nothing has been added as interpretation.
- [ ] The output is suitable for publication-oriented Persian editing.
