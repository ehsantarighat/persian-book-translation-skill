# Persian Translation Style Guide

## Translation Standard

The translation should read like professionally edited Persian prose prepared for book publication.

The style must be:

- Clear
- Fluent
- Faithful
- Modern
- Readable
- Publication-oriented
- Free from unnecessary complexity
- Free from omissions

## Core Style

Use Persian that is formal enough for print but not stiff or bureaucratic.

Prefer:

- روشن، دقیق، طبیعی
- جمله‌های قابل خواندن
- واژه‌های رایج و درست
- وفاداری به لحن نویسنده

Avoid:

- ترجمه تحت‌اللفظی
- جمله‌های انگلیسی‌وار
- واژه‌های سنگین بی‌دلیل
- «می‌باشد»، «نمود»، «مبادرت ورزید»، «نامبرده» unless the genre requires it

## Preferred Persian Choices

| Avoid | Prefer |
|---|---|
| می‌باشد | است |
| نمود | کرد |
| اقدام به ترک محل نمود | محل را ترک کرد |
| وی، used excessively | او |
| در راستای | برای / در جهت |
| مذکور | این / آن / یادشده |
| عدم وجود | نبود |
| با توجه به اینکه | از آنجا که / چون |

## Half-Space Rules

Use half-space in:

- می‌شود
- نمی‌شود
- کرده‌اند
- خانه‌ها
- آدم‌ها
- آن‌ها
- بی‌دلیل
- هیچ‌کس
- شکل‌گیری
- تصمیم‌گیری
- گفته‌شده
- ترجمه‌شده

## Punctuation Rules

Use:

- ، for comma
- ؛ for semicolon
- ؟ for question mark
- «...» for quotation
- — only when needed for parenthetical emphasis

Examples:

Correct:

`او گفت: «این تصمیم ساده نبود.»`

Incorrect:

`او گفت, "این تصمیم ساده نبود".`

## Paragraph Rules

Preserve paragraph structure from the source.

Do not merge paragraphs.

Do not skip paragraphs.

For very long source sentences, split them only when needed for Persian readability.

## Proper Names

First mention:

`نام فارسی (Original Name)`

Example:

`وینستون چرچیل (Winston Churchill)`

Later mentions:

`چرچیل`

For organizations:

`سازمان اطلاعات مرکزی آمریکا (Central Intelligence Agency / CIA)`

Later:

`CIA` or `سازمان اطلاعات مرکزی آمریکا`, depending on context.

## Numbers and Dates

Default:

- Persian digits in Persian text
- Full preservation of dates and numbers
- No conversion unless requested or helpful

Examples:

- ۱۹۴۵
- ۲۴ ژوئن ۱۹۴۱
- ۳۵ درصد
- ۱۲ مایل، حدود ۱۹ کیلومتر

## Translator Notes

Use translator notes only when necessary.

Format:

`[پیشنهاد یادداشت مترجم: ...]`

Never mix translator explanation into the author’s text.

## Dialogue

Use natural Persian dialogue.

Example:

`گفت: «نمی‌دانم.»`

Do not over-formalize dialogue unless the source is formal.

## Final Goal

The reader should feel that the translation is originally readable in Persian while still preserving the source text completely and faithfully.
